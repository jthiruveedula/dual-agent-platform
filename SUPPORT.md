# Support

This project is in early-stage open-source maintenance. Please use the channels below.

## Where to ask

- **Bugs and reproducible defects:** open a GitHub Issue with version, environment, command, expected vs actual behavior, and minimal repro.
- **Feature requests and design discussions:** open a GitHub Issue tagged `type:feature` or `needs-design` describing the use case and blast radius.
- **Security issues:** see [SECURITY.md](SECURITY.md). **Do not** post in public issues.
- **Questions about usage:** open a GitHub Discussion if enabled, or a `type:question` issue.

## What to include

- Repository commit SHA or tag.
- Python version, OS, and relevant cloud SDK versions.
- The plan JSON or command that triggered the behavior (redact secrets).
- Relevant log excerpts, redacted.

## Response expectations

This is a community-maintained project. Best-effort response. Critical safety issues are prioritized.

## Commercial / enterprise inquiries

Not currently offered. Forks and internal deployments are welcome under the project's license terms once declared.
