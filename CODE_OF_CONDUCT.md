# Code of Conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/) v2.1. Participation in this project (issues, PRs, discussions, code review) is expected to be respectful, professional, and focused on technical merit.

## Our standards

Examples of expected behavior:

- Use welcoming and inclusive language.
- Disagree on technical grounds; do not attack people.
- Accept constructive criticism gracefully.
- Prioritize what is best for the project and its users.

Unacceptable behavior:

- Personal attacks, harassment, or discriminatory language.
- Sustained disruption of discussion or review.
- Publishing others' private information without consent.

## Scope

This Code of Conduct applies in all project spaces (issues, PRs, discussions, mailing lists if any) and when an individual is representing the project in public spaces.

## Enforcement

Report unacceptable behavior to the maintainer privately via GitHub. Reports will be reviewed and acted on promptly. Maintainers may remove comments, close PRs, or block users who violate this Code.
